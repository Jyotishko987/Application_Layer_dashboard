# Wireside

A dashboard that visualizes DNS, HTTP, and SMTP protocol messages behind
Browsing, Mail, and Streaming activities.

## How to Run

Just double-click `index.html` — it opens in your browser, no install needed.

**Or** serve it locally:
```bash
python -m http.server 8000
```
Then open http://localhost:8000

## Files

- `index.html` — page structure
- `style.css` — styling
- `script.js` — app logic
